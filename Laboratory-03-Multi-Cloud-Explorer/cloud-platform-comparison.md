# Cloud Platform Comparison

## Side-by-Side Comparison

| Category | AWS | Azure | GCP |
|---|---|---|---|
| **Launched** | 2006 | 2010 | 2008 |
| **Market Position** | Largest market share, most services overall | 2nd largest, strong enterprise/Microsoft integration | 3rd largest, strong in data & AI/ML |
| **Compute Service** | EC2 | Virtual Machines | Compute Engine |
| **Storage Service** | S3 | Blob Storage | Cloud Storage |
| **Database Service** | RDS | Azure SQL Database | Cloud SQL |
| **Serverless Compute** | Lambda | Azure Functions | Cloud Functions |
| **Console/Portal Name** | AWS Management Console | Azure Portal | Google Cloud Console |
| **Key Strength** | Breadth of services, maturity | Hybrid cloud, enterprise/Windows integration | Data analytics, machine learning, Kubernetes |
| **Best Fit For** | General-purpose workloads at any scale | Enterprises already using Microsoft products | Data-heavy, AI/ML, and container-based workloads |

## Reflection Questions

**1. Which platform seemed the most beginner-friendly, and why?**
Based on my research, AWS's console appeared to be the most beginner-friendly overall, mainly because of the sheer amount of documentation, tutorials, and community support available. Since it's the most widely used platform, there are more learning resources built specifically for newcomers.

**2. Which platform would you personally choose for a new project, and why?**
For a general-purpose personal project, I would lean toward AWS because of the free-tier offerings and the wide range of services, which means I wouldn't need to switch providers as the project grows. However, if the project involved heavy data analysis or machine learning, I would choose GCP instead because of tools like BigQuery and Vertex AI.

**3. What surprised you most about comparing these three platforms?**
What surprised me most was how similar the core building blocks are across all three platforms — compute, storage, and databases all exist in some form on each one, just with different names and slightly different implementations. The real differences show up in each provider's specialty areas, like Azure's hybrid cloud tools or GCP's data/AI tools.

**4. How might a company decide between these providers in the real world?**
In practice, a company's decision often depends less on raw technical capability and more on their existing environment. A company already using Microsoft tools would naturally lean toward Azure, while a data-driven startup might prefer GCP. Cost, compliance requirements, and the skill sets of the existing IT team also play a major role in the decision.
