# Reflection

Going into this mission, I honestly thought AWS, Azure, and GCP were more or less interchangeable like three versions of the same thing with different logos. But after actually researching each one individually, I realized they each have their own personality, so to speak. AWS felt like the "does everything" platform with the biggest catalog of services. Azure felt like the platform built for companies that are already deep into the Microsoft ecosystem. And GCP felt like the platform built by people who really care about data and machine learning, which makes sense given tools like BigQuery and Vertex AI.

What surprised me the most was how similar the core building blocks actually are once you strip away the branding every platform has some version of a virtual machine service, an object storage service, a managed database, and a serverless compute option. The real differences show up in the details: how they're priced, how they integrate with other tools, and which specialty they lean into.

The client recommendation exercise was probably the most useful part for me. It forced me to stop thinking about these platforms in the abstract and actually apply them to real situations like realizing that a university would probably lean toward Azure because of Active Directory, while an AI research company would clearly benefit more from GCP's machine learning tools. That kind of thinking feels a lot closer to what an actual cloud engineer would need to do on the job.

The Linux investigation checkpoint also tied things together nicely. Looking at the small specs of the KillerCoda server and figuring out which cloud instance types (t3.micro, B1s, e2-micro) would be a realistic match made the whole "which cloud service should I use" question feel a lot more concrete instead of just theoretical.

Overall, this mission helped me move from just knowing that AWS, Azure, and GCP exist to actually understanding how to evaluate them and make a recommendation based on a business's specific needs. I feel like this is the kind of decision-making skill that matters just as much as the technical skills in cloud computing.
