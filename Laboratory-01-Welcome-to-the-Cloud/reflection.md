Reflection: Laboratory Activity 2 – Mission 1: Welcome to the Cloud
Honestly, when I first saw this whole mission, I was a bit nervous because I wasn't used to working with a terminal. All those command lines looked intimidating at first, but once I actually started, I realized it wasn't as hard as I thought  I just had to be careful with the exact syntax. I actually made a mistake early on  I forgot to include the slash before /bin/bash, which caused my adduser command to fail. That's when I really understood how even a tiny typo can throw off the whole process in Linux.
The part where I had to create a new user account, check system information, and organize folders seemed simple at first, but I realized these are actually things that matter a lot in real work. Before migrating a server to AWS or Azure, you first need to know exactly what you're working with  how much RAM it has, how much disk space is available, and so on. It made me appreciate that being a cloud engineer isn't just about clicking buttons on a cloud platform; there's a whole foundation you need to understand first.
Building my GitHub portfolio was also surprisingly useful. I used to think you could just upload everything and call it done, but I learned that the structure actually matters  the right folders, the right file names  because otherwise it becomes hard for other people (or even future me) to find anything. I did run into a few hiccups, like accidentally putting a file in the wrong folder and having to move it, but that taught me to slow down and double-check my work before committing changes.
Overall, this activity showed me that even the "small" tasks, like checking system specs or organizing a repository properly, are actually part of what real cloud engineers do every day. I'm looking forward to the next mission  I feel like it'll be a bit easier now that I'm getting more comfortable with Linux and GitHub.
